# てもとフォト

写真を**端末の外に出さずに**編集できる写真編集Webアプリです。アップロードもアカウントも要りません。ブラウザの中（GPU と端末内の保存領域）だけで動き、一度開けばオフラインでも使えます。

## できること

- **画面**: Canva の編集画面のように、上にグラデーションの見出し（元に戻す・書き出し）、左（スマホでは下）に道具の列（おまかせ・調整・切り抜き・部分補正・レタッチ・フレーム・情報）、その右にパネル。パネルは閉じて写真を広く見られる。右下で表示の拡大・縮小。画面の色は、写真一覧の右上のアイコン（編集画面は「⋯」メニュー）を押すたびに 自動（端末の設定に合わせる）→ ライト → ダーク と切り替わる。使わない道具は「⋯」メニューの「表示する道具を選ぶ」で隠せる（最初は調整・切り抜き・部分補正を隠している。隠しても編集は残る）。「スペシャリストモード」をオンにすると、隠した道具も全部出る。見出しの「◧」はタップで編集前と切り替え（長押しなら押している間だけ）。スマホの写真一覧では、選んだ写真の操作が画面の下のバーに出る
- **補正**: 露光量・明るさ・コントラスト・ハイライト・シャドウ・白レベル・黒レベル・色温度・色かぶり・彩度・自然な彩度・明瞭度・かすみの除去・シャープ・ノイズ除去
- **効果**: 周辺光量・粒子・フェード・ブルーム・ハレーション
- **色**: トーンカーブ、HSL（8色）、カラーグレーディング、フィルター27種（強さを調整できる。成人式・振袖などの記念写真向けの「透明感」「振袖あでやか」「スタジオ白」「和モダン」「ふんわり」を含む）、自動補正
- **美肌**: 端末の中で動く AI（MediaPipe）が人物の肌（顔・首・腕・手）を見分け、肌だけのムラ・赤み・くすみを整え、明るくする（髪・服・背景は白くしない。肌のきめ・口紅は残す。判定した範囲を赤で確認できる）。AI が使えない端末や人物の写真でないときは、タップした肌の色相に近く、そこからつながっている場所を肌とする。「写真館風におまかせ仕上げ」で、自動補正・美肌・フィルターを一度に
- **写真館の仕上げ**（レタッチ）: なぞるだけで使えるブラシ。**形**（輪郭・あご・腕を、なぞった向きに少しずつ動かす。なぞりながら見える。なぞり始めの指の後ろ側の背景（壁・柱など）と、押す先にある別の物は動かさないので、背景がゆがまない）、**目元・歯**（白目の赤みを減らして明るく、黒目・まつげをくっきり、くまを薄く／歯の黄ばみだけを取って白く。唇・歯ぐきの赤は変えない）、**明暗**（明るく＝覆い焼き・暗く＝焼き込み。鼻筋を明るく、輪郭を暗くして立体的に）、**リップ**（唇を丸で囲むかタップすると、AI が見つけた唇の全体（上唇・下唇）に色をのせる。「なぞった所だけ」にすると、なぞった所の唇にだけ。歯・肌には色が付かない。元の唇の明暗・色の濃淡を残すので、ベタ塗りにならない。ピンク・コーラル・レッドなどの色見本と、色合い・濃さ・明るさで色を調整できる）、**しわ取り**（着物・服のしわやほうれい線の陰だけをならす。同じ素材（色みが近い所）だけで明るさをならすので、布目・柄・肌のきめと、服と肌の境目は残る）。どれも元の写真は変えず、なぞった線だけを保存して、書き出すときは元の大きさで同じように当てる
- **被写体ブレの補正**: シャッターが間に合わずにぶれた手・髪・顔を、端末の中で動く AI（NAFNet）がくっきりさせる（平らな所・肌はそのまま。写真は外に送らない。はじめて使うときに約 65MB を読み込む。WebGPU があれば GPU で、なければ CPU で計算し、写真の上に「残り○%」を出す）
- **部分補正**: 円形・グラデーション・ブラシで、選んだ場所だけ補正
- **修復**: スポット修復、モザイク、ぼかし
- **切り抜き**: 比率（L判・2L判・六つ切り・A4 のプリント比率を含む）・回転・反転・傾き補正・遠近補正
- **フレーム**: 枠・角丸・余白（SNS の比率に合わせる）
- **RAW**: キヤノン（CR3・CR2）・ニコン・ソニー・富士フイルムなどの RAW を、RAW データから 16bit で現像（[LibRaw](https://www.libraw.org/) を WebAssembly にしたものを端末の中で動かす）。編集中は半分の大きさで表示し、書き出すときは元の大きさで、細かい所の色にじみが出にくいデモザイク（DHT）で現像し直す。「RAW」タブで、RAW の露出（白飛び・黒つぶれした所の階調を戻す）・ノイズ除去（写真ごとにノイズの量を測り、平らな所だけならす）・シャープ・色にじみの自動補正・周辺の暗さ・ゆがみの補正を、RAW データから現像し直して調整できる。RAW は編集も 16bit の細かさで行うので、強く編集してもグラデーションに縞が出ない。読めないものは中のプレビュー画像で開く。DNG はこのアプリの現像で開く
- **グリッド**: 2〜9枚を1枚にまとめる（29レイアウト。写真の間の線をドラッグして大きさの割合も変えられる）
- **書き出し**: JPEG・PNG・WebP、大きさを指定、まとめて書き出し。位置情報などのメタデータは入らない。iPhone などでは「写真アプリに保存」で共有メニューを開き、「画像を保存」で写真アプリに直接入れられる（「書き出す」はファイルアプリ・ダウンロードへ）
  - **元の大きさ**: 編集中は端末が扱える大きさ（約1,670万画素まで）に縮めて表示し、書き出すときは元の写真から描き直す（JPEG・PNG）。iPhone の Safari でも、画像を帯に分けて描き、自分で JPEG / PNG を組み立てるので、2,400万・4,800万画素の写真もそのままの大きさで書き出せる
  - **色**: iPhone の写真の Display P3（sRGB より鮮やかな赤・緑）のまま読み込み・編集・書き出しする。プリント店向けに sRGB も選べる
- **非破壊編集**: 元の写真は残したまま。いつでも元に戻せる。編集のコピー・貼り付け、プリセット

一般的な写真編集アプリとの比較や仕組みは [`docs/photo-editor.md`](docs/photo-editor.md) にあります。

## 使い方

### スマホ・パソコンで使う（公開版）

GitHub Pages で公開している場合は、そのアドレスを開くだけです。スマホでは「ホーム画面に追加」すると、アプリのように使えます。

### 自分のパソコンで動かす

Python 3 があれば、次の1行で起動できます（ビルドは不要です）。

```bash
python3 -m http.server 4173   # Windows は py -m http.server 4173
```

ブラウザで http://localhost:4173/ を開きます。`index.html` をダブルクリックして開くと動きません（ブラウザの決まりで、部品のファイルを読み込めないため）。

### GitHub Pages で公開する

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** にする
2. main に変更を入れる（または Actions タブから「Deploy to GitHub Pages」を手動実行）
3. テストが通ると `https://<ユーザー名>.github.io/<リポジトリ名>/` に公開される

## データについて

- 写真と編集内容は、使っているブラウザの中（IndexedDB）にだけ保存されます。外部には送られません（CSP で外部への通信そのものを禁止しています）
- ブラウザのデータを消すと、保存した写真も消えます。大事な写真は書き出して保存してください
- アドレスが違うと保存場所も別になります（例: `localhost` と公開版では別々）

## テスト

```bash
npm install
npx playwright install chromium   # 初回だけ
npm test                          # セキュリティチェック・単体テスト・画面のテスト
```

- `tests/unit/`: 編集レシピの検証、座標変換、カーブ、自動補正、Exif、修復、美肌、RAW の現像（DNG・LibRaw の出力の仕上げ）、グリッドの計算
- `tests/e2e/`: 実際のブラウザで、画素の変化・書き出し（元の大きさ・Display P3）・保存・RAW・グリッド・アクセシビリティを確認

### 自動マージ

PR の CI（`.github/workflows/ci.yml`）が通ると、`.github/workflows/auto-merge.yml` がその PR を main にマージし、公開版（GitHub Pages）を更新します。
- 下書き（Draft）の PR・フォークからの PR・main 以外へ向けた PR はマージしません
- テストしたコミットが PR の最新のときだけマージします
- 自動でマージしたくない PR には `no-auto-merge` ラベルを付けてください
