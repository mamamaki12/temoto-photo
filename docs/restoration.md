# 写真復元の開発メモ

2026-10-24時点。専用ブランチで開発中、公開版には未反映。

## 画面から使える第一段階

- 「おまかせ→自動補正」の「写真全体の明るさ補正」で顔・腕・衣装・背景をまとめて明るくする。リニアRGBに共通の倍率を掛け、明部はなめらかに保護する。白バランスは変更しない。
- 補正量は非破壊レシピ `adj.lowlight`（0〜100）に保存。Undo、プリセット、プレビュー、通常書き出し、元解像度の書き出しで同じ描画処理を使う。従来の写真は0のまま。
- 同じ画面の「ノイズ軽減」は既存の軽量処理。下記の高精度Workerはまだ接続していない。実写真での品質検証と端末のメモリ評価が必要。
- 1枚の書き出しに進捗バーを追加。元解像度の画像生成は既存の処理量通知から残り%を表示する。読み込み・通常のCanvas書き出しなど進捗を測れない工程は不定表示。これは推定残り時間でも、写真アプリへの保存完了表示でもない。
- 顔や指を生成して置き換える処理、動体ぶれの復元は含まない。

## 実装済み

- `restoration.js`: 3×3パッチのNon-local meansで同じ模様の画素を平均し、その後に露出を変更する。Float32のリニアRGBを受け取り、1を超える明るさも保持する。入力は変更しない。
- `restoration-worker.js` / `restoration-client.js`: 端末内Worker。処理済みタイル数を通知し、AbortSignalでWorkerを終了する。元データをコピーして転送する。
- 色成分共通の重みを使う。タイルの外側も元画像から参照し、タイル境界に線を作らない。

```js
import { restoreInWorker } from './restoration-client.js';

const controller = new AbortController();
const result = await restoreInWorker(
  { width, height, data: linearRGB }, // Float32Array、RGBの順。8bitのsRGB値をそのまま渡さない
  { noiseSigma: 0.01, strength: 1, exposureEV: 2 },
  {
    signal: controller.signal,
    onProgress: ({ percent }) => {
      // このコアの進捗のみ。表示用には全工程の進捗へ換算する。
      progress.value = percent;
      label.textContent = `残り${100 - percent}%`;
    },
  },
);
// controller.abort() で中止。result.dataにも1を超える値があるため、表示前にトーン処理が必要。
```

## 制限と次の作業

1. `noiseSigma`は入力のリニア値と同じ単位の標準偏差。現状は一定の独立したノイズを仮定する。実写真に必要な、信号依存ノイズの推定・分散安定化・色ノイズ処理は未実装。勝手に固定値を全画像に当てない。
2. 色空間の変換はしない。同じ色空間のリニアRGBで入出力する。JPEG/P3の伝達関数を解き、RAWのRec.2020を既存の現像工程のどこで接続するか決める。現状は非負画素のみ対応。RAWの行列変換による負値も扱うか検討する。
3. 明るくして失われた情報が戻る処理ではない。トーン処理・色域処理・16bit描画用の残差は既存パイプラインと接続してから評価する。露出を二重に適用しない。
4. レシピの保存・検証・Undo・写真切替時の中止・結果のキャッシュ・元解像度書き出し・オフライン動作へ接続する。表示用の縮小画像だけを復元して完了としない。画像をコピーするため、元解像度のメモリ上限とSafari実機での検証が必要。
5. 読み込み、RAW現像、ノイズ推定、復元、合成、書き出しの工程を進捗バーに反映する。現状の100%はノイズ除去・露出コアの完了で、保存完了ではない。
6. 手ぶれ・部分的な動体ぶれの補正は未実装。空間的に異なるぶれに対応する復元モデルについて、重みのライセンス・端末内推論・容量・肌や指の自然さを評価する。単なるシャープ化で代用しない。
7. 添付写真はこのセッションでは受け取れていない。暗所・高ISO・手だけ動いた写真と、可能ならRAWを再取得。肌、髪、文字、布目、指、輪郭の二重線、色にじみを100%拡大で比較する。合成ノイズのテスト合格だけで実用品質と判断しない。

候補の学習済みモデルは未導入。既存の美肌用AIとは別の処理として選定する。
