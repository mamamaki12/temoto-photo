# リップ・歯の範囲の自動化 引き継ぎメモ（2026-10-25）

ブランチ: `claude/lip-teeth-auto`（`claude/kind-hopper-jnlyd3` から分岐。PR 未作成）

## できたこと
- リップ・歯とも、なぞった所・タップした所は「目印」。範囲はアプリが自動で決める（`app.js` の `fxAction`、`op.whole = true` と `op.lips`）。
- `skinseg.js` の `findMouth`: 目印のまわりを狭い方から（目印の大きさの 5・10・20・40 倍）切り出して FaceLandmarker に渡す。舞台・集合写真の小さな顔も見つかる（10/24 の写真で試した 35 個すべて見つかった）。最後に写真全体でも探す。
- `brushfx.js` の `segmentMouth`: 口のまわりを 肌・唇・歯・口の奥 の 4 つに塗り分ける。
  - AI の輪郭は目安（prior）。確かな所から各クラスの色（Y・Cb・Cr）の正規分布を 2 つずつ（明るい／暗い）覚え、画素ごとの事後確率を出し、となりと揃うよう 4 回ならす（mean-field）。分けた結果で分布を作り直してもう 1 回。
  - 歯の種（確かな歯）は内側の輪郭の中だけから取る（唇のつやを拾わない）。口の中の明るい方 6 割・肌と比べて赤みが少ない所。種が少なければ歯なし（口を閉じている）。
  - 上の歯は内側の輪郭の上の線より上にはほぼ出ない、として歯の prior を下げる（日の当たった上唇対策）。
  - 歯は、確かな歯と唇の赤み（緑÷赤）の中間で切る（歯ぐき・濡れた下唇）。暗い写真は境目を唇寄りにして広くならす。
  - 小さな歯のかたまりは、口の中にあって、大きいか口の奥（暗い所）に接しているものだけ残す。
- 歯の白さ: 黄ばみを、まわりの肌の色の 0.55 倍の淡い色に寄せる（照明の色は残す）＋少し明るく。
- テスト: `tests/unit/mouth.test.js`（作りものの口）、`tests/e2e/photo-ai.spec.js`（歯のタップ・閉じた口）。単体 58・画面 69 すべて通過。

## 残っていること（ユーザーが改善を希望、2026-10-25）
1. 口の端の影に入った奥の歯が範囲から外れる（IMG_9471 の 2 人目＝左の人、口の左端の奥歯）。
   - 塗り分けの段階では一部「歯」になっているが、歯の赤みの切り（`mid`）と小さなかたまりの除外で消えている様子。影の歯は暗いので、明るさ別の 2 つの分布でも拾いきれていない。
2. 強い日差しの写真で、歯のすぐ上の上唇が少し歯の範囲に入る（IMG_9516 の左端の人）。
   - 上唇が日に当たって淡いピーチ色になり、唇の種（肌よりはっきり赤い所）から外れ、歯の色の分布に近い。
